Auth / signup flow (decoded)

  • Header Sign in → dispatch opens register/login modal (not immediate redirect).
  • Modal CTA → Kinde login() / register() with orgCode.
  • After redirect, JWT stored (sessionStorage in production); payload decoded client-side for sub, permissions, external_id.
  • Guest: auto-generated guest_user_id in localStorage on first visit.
  • Silent SSO: query param triggers kindeLogin({ prompt: none }); post-auth destination saved in localStorage.
  • Onboarding: username availability check → display name → age + ToC checkboxes → community guidelines modal.
  • API: POST /v2/users/external, GET/PATCH /v1|v2/users, POST /v2/auth/refresh.
